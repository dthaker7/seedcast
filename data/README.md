# Frozen Apple market dataset

`aapl_daily_2015_2017.csv` is an unchanged frozen copy of Plotly's `finance-charts-apple.csv` dataset.

- Source repository: https://github.com/plotly/datasets
- Source file: https://github.com/plotly/datasets/blob/master/finance-charts-apple.csv
- Direct source used: https://raw.githubusercontent.com/plotly/datasets/master/finance-charts-apple.csv
- Retrieved: November 13, 2026
- Rows: 506 data rows plus one header
- Date range: February 17, 2015 through February 16, 2017
- Canonical SHA-256 (UTF-8 text with LF line endings): `04053fd4ab339dd81a2bd14153e4be4fd88ae209fbc7aca29bc1096a3cbe7f27`

The Plotly datasets repository is distributed under the MIT License. A copy is stored in `PLOTLY_DATASETS_LICENSE.txt`. The repository does not identify the upstream market-data vendor for this specific file, so this sample is used only for the INFO 490 educational feasibility experiment. The team must select and license an appropriate source before production use.
